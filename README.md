# Litoral Club - Catálogo Web Oficial

Sitio web estilo DC Shoes para la marca **Litoral Club** (Gorras & Streetwear), preparado para desplegarse gratis en **Cloudflare Pages** y **GitHub**.

## Estructura de archivos:
- `index.html`: Estructura con pestañas (Inicio con banners, Gorras con buscador y Contacto).
- `style.css`: Estilos visuales oscuros/urbanos inspirados en DC Shoes y diseño adaptativo a celulares.
- `app.js`: Carrito de compras, buscador y enlace de pedidos a WhatsApp.
- `products.json`: Lista de gorras con fotos, precios y categorías (fácilmente editable).
- `assets/`: Carpeta para guardar tu foto de logo e imágenes propias.
